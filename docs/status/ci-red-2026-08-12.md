## 2. `agent-engine` — uchta ketma-ket xato (TUZATILDI, `ab05358`)

Ish BIRINCHI qadamda yiqilardi, ya'ni ruff/mypy/pytest umuman ishga
tushmagan — shuning uchun quyidagi 2- va 3- xatolar shu paytgacha
KO'RINMAGAN edi.

### 2.1 `pip install -r requirements.txt` -> `ResolutionImpossible`

```
The user requested pydantic==2.10.4
google-genai 2.11.0 depends on pydantic<3.0.0 and >=2.12.5
```

`google-genai` 2.11.0 (Phase 5 dan oldin qo'shilgan) `pydantic>=2.12.5`
talab qiladi, `requirements.txt` esa `pydantic==2.10.4` ni qotirgan edi.
Bu ikkala Python ishini ham (`agent-engine` VA `pip-audit`) butunlay
bloklardi.

**Tuzatma:** `pydantic` 2.10.4 -> **2.13.4**. BITTA qator; boshqa hech
bir pin o'zgarmadi; major ko'tarilmadi (2.x ichida). Qolgan barcha
cheklovlar qanoatlanadi (fastapi `<3`, langchain-anthropic `>=2.7.4`,
anthropic `>=1.9`, pydantic-settings `>=2.7.0`).

### 2.2 `mypy` — `llm_utils.py` da 3 ta `union-attr`

`_anthropic` / `_gemini` / `_gemini_types` — modul darajasidagi
`Any | None` global. "Provayder tanlangan bo'lsa client ham bor"
invarianti FUNKSIYALAR ORASIDA, mypy uni ko'ra olmaydi.

**Tuzatma:** `type: ignore` EMAS — **haqiqiy qorovul**
(`if _anthropic is None: return None`). Modulning e'lon qilingan
shartnomasi ("kalit yo'q -> None") shundoq ham aynan shuni talab qiladi.

> **Phase 5 auditining tashxisi NOTO'G'RI edi.**
> [`phase5-observability-audit.md`](phase5-observability-audit.md) §13.4
> bu 3 xatoni "lokal Python 3.14 drift'i, CI 3.11 da ishlaydi" deb
> yozgan. Xatolar CI'ning aynan **3.11** muhitida ham chiqadi —
> tekshirildi.

### 2.3 `mypy` — `agent_engine.py` da yana 3 ta (YASHIRIN edi)

Bular faqat bog'liqliklar HAQIQATAN o'rnatilganda ko'rinadi: langchain
o'rnatilmagan bo'lsa `--ignore-missing-imports` ularni yutib yuborardi.

**a) `_reason_node` — HAQIQIY ish-vaqti xatosi, tip-shikoyati emas.**
`response.content` `str | list` bo'lishi mumkin (Anthropic
kontent-BLOKLARI `list` qaytaradi), `AgentState["messages"]` esa
`list[dict[str, str]]`. `list` yozilganda `_halal_check_input` dagi
`.lower()` yiqilardi:

```
AttributeError: 'list' object has no attribute 'lower'
```

Empirik tasdiqlandi. **Tuzatma:** `_content_to_text()` normalizatori
(matn bloklarini birlashtiradi, `tool_use` kabi matnsiz bloklarni
o'tkazib yuboradi, natija HAR DOIM `str`).

**b) `ChatAnthropic(model=..., max_tokens=...)`** — TOR
`type: ignore[call-arg]`. Bular HAQIQIY maydonlar, lekin `model_name` /
`max_tokens_to_sample` aliaslariga ega va `populate_by_name=True`, ya'ni
ish vaqtida to'g'ri ishlaydi (`ChatAnthropic.model_fields` bilan
tekshirildi). Aliaslarga o'tish langchain'ning hujjatli ommaviy
API'sidan chekinish bo'lardi.

**Testlar:** +7 (43 -> **50**). `_content_to_text` uchun 4 ta, llm_utils
qorovullari uchun 3 ta.
